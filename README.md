# CassetteUrn

Transforms existing cassette tape collections into a digital archive with metadata and tag organization for music enthusiasts.

With CassetteUrn, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/CassetteUrn.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure CassetteUrn, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
